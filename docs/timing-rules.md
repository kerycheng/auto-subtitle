# 打軸規格

## 規則優先順序

1. 時間合法，且不超出媒體範圍。
2. 保留估計發聲區間與完整辨識詞，避免為符合顯示長度裁字。
3. 句首先行量預設 20ms，可調整；這是顯示參數，不是聲學精度保證。
4. 尾留與延長不製造新的相鄰重疊；真實發話重疊保留並提示。
5. 最短顯示預設 500ms，受下一句、尾留上限及媒體結束限制。
6. 一般尾留預設 200ms、上限 500ms；剩餘空隙嚴格小於 300ms 時，受上限限制補齊。

長音經確認後可收在估計發聲結束，不為滿足最短時間而延長。既有人工鎖定內容重新打軸時保留。

## 分段與邊界

新建日文專案以 Whisper 原生分組為基礎，保留來源時鐘、詞語及所有權。只有過長或字數過多時才細分，避免僅因短停頓切碎原句。其他策略以詞界、標點、停頓與長度限制分段，不臆造詞內時間。

超過目標時長時優先尋找適當詞界；單一詞組本身超限則保留並提示。VAD 只輔助邊界，不能據此直接判定漏詞或刪除文字。保守策略在 VAD 建議裁短句尾時保留原始詞尾。

一般開始時間為 `max(0, speech_start - lead)`；結束參考發聲結束、尾留、最短顯示、相鄰句及媒體範圍。不能為滿足最短時間、尾留或補齊空隙裁掉本句發聲。

ASS 以百分之一秒輸出，SRT 以毫秒輸出；匯出量化後的非法區間拒絕輸出。自動兩行換行預設關閉，啟用時仍保留原文。

## 驗證範圍

單元測試覆蓋短句、尾留上限、空隙門檻、媒體尾端、鎖定內容、詞所有權及真實重疊。這些程式規則驗證不等同原語正確率、自然句界品質或發聲邊界精度驗收；後者需要獨立人工校對的原語與聲學參考。
