自動打軸機 0.9.5 · Windows

主要流程：匯入影片／音檔 → 選語言與模型 → 生成字幕 → 匯出 ASS／SRT → Aegisub 人工修整。
字幕表為唯讀預覽；預設隱藏內建修軸、拆合、候選採用與人工複核工具。
「進階設定」保留音軌、詞彙提示、打軸參數及音訊輸出，不必在本程式內修軸。

建議先用 1–20 分鐘單檔素材。選取字幕會高亮並定位波形，按「試聽選取句」才播放。
F5 暫停／原位置繼續，Ctrl+↑／↓ 切換句子，F6／Shift+F6 導覽生成提示。
下方可調音量；進階設定可選喇叭／耳機。換句、切換輸出裝置會停止舊試聽。
ASS／SRT 預設不插入兩行換行，需要時可在進階設定勾選。

新建日文專案保留 Whisper 原生句界，短停頓不強制拆句，過長／過多字才細分。
打軸參數仍可調整；「套用參數」利用已辨識詞重新分段，不重跑模型。
舊專案沿用舊辨識策略，需新建日文專案重新辨識才能取得原生句界。
混語、重疊發話、BGM、專有名詞與漏詞仍需在 Aegisub 聽辨校正；生成提示不等於錯誤判定。
取消時保存完整辨識批次；可接續，GPU 失敗後可從「專案與工具」改用 CPU 繼續。

請保留整個可攜版目錄，包括 exe、_internal；GPU 版另保留 cuda。
版本目錄與 exe 名稱可包含版本號。建議雙擊根目錄 Start-AutoSubtitle.cmd 使用已下載模型。
模型外置，不隨 exe 打包；可指定本機 CTranslate2 模型資料夾離線辨識。
0.9.5 會隨新辨識進度保存解碼診斷紀錄，操作方式不變，舊結果不補猜缺少的紀錄。
GPU 版附 CUDA 12.4／cuDNN 9.1 執行庫，仍需相容 NVIDIA 驅動；只在選 cuda 時載入。
版本更新時保留媒體、*.autosub.json、*.cache、*.review 與外置模型。
搬移媒體可重新連結；保留分析 WAV，程式會核對音訊後沿用字幕。
舊專案首次存檔前保存對應 .v1.bak／.v2.bak／.v3.bak；新版專案勿用舊程式覆寫。

目前已在 Windows 11 驗證，Windows 10 實機測試待辦；macOS 暫緩。
