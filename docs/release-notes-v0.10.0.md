# 自動打軸機 · Auto Subtitle v0.10.0 發佈說明與更新日誌

本機執行的多語言字幕自動打軸工具，支援日文、中文、英文與韓文音訊／影片素材，整合 **faster-whisper**、**Silero VAD** 與日文斷詞（**SudachiPy／BudouX**），提供多組詞彙提示勾選、逐句波形試聽與 **ASS／SRT** 字幕匯出，銜接 Aegisub 翻譯與人工修軸流程。

## v0.10.0 更新日誌（Changelog）

### 新增與強化功能

- **解碼診斷紀錄（Recognition Trace Checkpoints）**：
  - 新辨識進度在每個完整解碼批次提交時，會自動將解碼觀測紀錄（模型設定、時間區間、詞級 SHA-256 雜湊摘要與分段統計）寫入專案檢核事件。
  - 詞彙提示（`initial_prompt`、`prefix`、`hotwords`）僅記錄 SHA-256 雜湊值，不重複落盤私人提示原文。
  - 中斷辨識並於後續接續執行時，會保留既有批次紀錄並精確銜接剩餘時間區間；既有舊版專案不補猜缺少的診斷紀錄。
- **日文 Whisper 原生句界辨識管線（`native-v1`）**：
  - 新建日文專案預設保留 Whisper 原生句界與來源時鐘區間，僅透過 Silero VAD 排除超過 5 秒的長靜音區段（保留前後 1 秒語境緩衝），避免短停頓切碎完整語句。
  - 僅在單句過長或字數超過上限時，才結合 SudachiPy／BudouX 與詞界規則進行細分。
  - 「套用參數／重新分段」直接使用已辨識的詞級時間資料重算句首先行、尾留與最短顯示時間，無須重新執行模型推論。
- **多組詞彙提示清單勾選與快照保護**：
  - 支援在「選擇提示清單…」同時勾選多組本機詞彙清單（如主播名稱、遊戲報點、角色／武器術語），即時預覽合併並自動去重（保留原始大小寫與順序）。
  - 搜尋過濾詞彙清單時，已勾選但暫時隱藏的清單仍會維持勾選狀態。
  - 當本機詞彙清單日後修改或刪除、無法重現舊專案當下的提示組合時，自動保留原提示文字快照，避免靜默改寫既有專案。
- **匯出優先的淺色介面與精準逐句試聽**：
  - 主畫面採用淺色主題，預設聚焦「匯入 → 辨識 → 逐句試聽 → 匯出 ASS／SRT」流程，隱藏生成提示欄、篩選與內建修軸工具（進階專案工具可透過環境變數 `AUTOSUB_ENABLE_PROJECT_TOOLS=1` 開啟）。
  - 「試聽選取句」嚴格裁切並播放該字幕軸的開始至結束時間，不外溢前後相鄰音訊；支援 `F5` 暫停／原位續播、`Ctrl+↑／↓` 切換字幕句、循環試聽與音訊輸出裝置切換。
- **專案格式（Schema v4）與檔案寫入保護**：
  - 舊版專案（v1／v2／v3）首次升級存檔前，自動於同目錄建立 `.v1.bak`、`.v2.bak` 或 `.v3.bak` 完整備份。
  - Windows 專案與詞彙庫存檔採用暫存檔原子替換（`replace_checkpoint`），針對暫時性檔案鎖定（WinError 5／32／33）提供有限次退避重試，失敗時保留雙邊快照且不刪除舊檔。

請依電腦硬體環境下載對應的 `.zip` 壓縮包，並**完整解壓縮整個資料夾**（請勿單獨拉出 `.exe` 執行）：

| 檔案名稱 | 適用環境 | 推論運算模式 | 內含執行檔與必要目錄 |
| --- | --- | --- | --- |
| `AutoSubtitle-0.10.0.zip` | 一般電腦／無相容 NVIDIA 顯卡 | CPU（`int8`） | `AutoSubtitle-0.10.0.exe`、`_internal/`、`licenses/`、`LICENSE.txt`、`README-zh-TW.txt` |
| `AutoSubtitle-GPU-0.10.0.zip` | 具備相容 NVIDIA 顯示卡與驅動 | CUDA（`float16`）或 CPU | `AutoSubtitle-GPU-0.10.0.exe`、`_internal/`、`cuda/`（CUDA 12.4／cuDNN 9.1）、`licenses/`、`LICENSE.txt`、`README-zh-TW.txt` |

### 執行與升級注意事項

- **首次模型下載**：可攜版不內嵌語音辨識模型。首次執行選定模型（`tiny`、`base`、`small`、`medium`、`large-v3`、`turbo`）時需連網自動下載，或於「進階設定」指定本機已下載的 CTranslate2 模型資料夾離線使用。
- **系統相容性**：已於 Windows 11 驗證；GPU 版需安裝相容的 NVIDIA 顯示卡驅動程式（僅在選用 `cuda` 裝置時載入 `cuda/` 目錄下的執行庫）。
- **版本升級保留項目**：從舊版（`0.9.x`）更新時，請保留原始媒體檔、`*.autosub.json`、專案快取（`*.cache`、`*.review`）、外置 `models/` 資料夾與本機詞彙設定，並避免使用舊版程式覆寫已升級為 v4 的專案檔。
- **完整性驗證**：各可攜版目錄內的 `release.json` 記錄了執行檔的 `executable_sha256` 雜湊值與第三方日文斷詞套件版本資訊，可供核對檔案完整性。
